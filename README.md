# iLoveNime.v2

Personal local ILoveNime anime tracker with an Animasu proxy.

## Menjalankan secara lokal

```bash
npm install
npm start
```

Buka alamat localhost yang ditampilkan oleh server.

## Pengujian

```bash
npm test
npm run test:all
```

Proyek ini dikonfigurasi untuk penggunaan lokal. Jangan menambahkan kredensial atau file `.env` ke repositori.
